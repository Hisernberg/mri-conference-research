# QMMF-Net

Reference implementation of the master research plan **`qmmf-v1.0`** —
*Quality-Conditioned Masked Moment Fusion for Calibrated Brain Tumour
Segmentation with Arbitrary Missing MRI Modalities*.

**This repository contains no experimental results.** Every performance figure
in the plan is a planning target or a decision gate. The code produces
measurements; the notebooks record them.

## Dual-T4 execution

Two 16 GB T4s are **two devices, not one 32 GB device**. The default is
experiment-level parallelism: each GPU runs an independent single-GPU process
that claims work from a shared, lock-protected queue and appends to a shared
ledger.

```python
from qmmf.worker import build_experiment_queue, launch_dual_gpu, wait_for

build_experiment_queue("artifacts/queue.json",
                       models=["unet2d", "unet25d", "hemis25d", "qmmf_net"],
                       folds=[0, 1, 2, 3], seeds=[42])
procs = launch_dual_gpu("scripts/run_worker.py", "artifacts/queue.json",
                        "artifacts/ledger.csv",
                        ["--cache", "/kaggle/working/cache",
                         "--splits", "artifacts/adult_splits.json",
                         "--manifest", "artifacts/manifest.csv",
                         "--time-budget", "36000"])
wait_for(procs)
```

Interrupted runs resume from `last.pt`; stale queue claims are reclaimed after
six hours; a run that OOMs is recorded as `resource_rejected` rather than
disappearing.

## Design decisions worth knowing about

**Absent modalities cannot leak.** Masking happens in three places: inputs are
zeroed, the softmax denominator excludes absent modalities, and the max branch
masks with a finite sentinel. `tests/test_model.py::test_absent_modality_cannot_influence_output`
perturbs an absent modality by 50σ and asserts the output is unchanged.

**Label semantics are verified, never assumed.** MSD Task01 (`1=edema, 2=non-enhancing,
3=enhancing`) and BraTS-legacy (`1=necrotic, 2=edema, 4=enhancing`) map the same
integers to different regions. `infer_label_scheme` reads `dataset.json`, checks
it against observed values, and raises rather than guessing when ambiguous.

**Shapley values are exact.** With four modalities there are 15 non-empty
subsets, all of which are evaluated, so no Monte Carlo approximation appears
anywhere. The efficiency axiom is asserted numerically in the notebook, not
assumed. `v(∅) = 0` is a stated convention, not a hidden one.

**Empty ET references are handled explicitly.** Both-empty scores 1.0 but is
flagged and reported in its own column; empty-reference-with-prediction scores
0.0 and is counted as a false-positive case. The primary macro Dice excludes
empty-reference regions so free 1.0s cannot inflate the headline.

**Deep-supervision heads run in training mode only** — at inference they would
be wasted T4 compute.

**The gate's final linear layer has no bias.** Gate logits enter a softmax over
modalities, so a shared additive constant is unidentifiable and would sit in
the model with a permanently zero gradient.

## Measured, not planned

The plan's Figure "accuracy–efficiency design target" places QMMF-Net near
7.5M parameters. At the plan's own widths `[24, 48, 96, 160]`, this
implementation measures **1.22M parameters** — comfortably inside the < 8M gate,
but well below the illustrative point. That figure is explicitly labelled a
planning estimate in the plan, and the discrepancy reflects block design
choices (depthwise large kernels, a light decoder), not a violated constraint.
If the pilot shows the model is under-capacity, widen it and re-measure —
`scripts/make_configs.py --check-parameter-match` re-derives the A16
parameter-matched control automatically.

Peak VRAM and throughput are **not** measured here: this repository was
developed and tested on CPU. `speed_and_memory_pilot` in
`src/qmmf/trainer.py` produces those numbers on a real T4, and Notebook 02
cell 09 gates on them (G1).

## What has and has not been verified

Verified by the test suite on synthetic data:

- label mapping, nesting invariant, and refusal under an unverified scheme
- 15-subset enumeration and curriculum sampling
- masked softmax and masked max under absent modalities
- absent-modality non-influence (numerically)
- parameter budget and A16 parameter matching
- exact 2.5D → 3D reconstruction round-trip
- split disjointness, OOF coverage, nested label subsets, tamper detection
- Shapley efficiency, symmetry and null-player axioms
- Holm correction, bootstrap CIs, permutation test, non-inferiority rule
- metrics against hand-checkable toy cases, including the empty-reference rules
- a two-epoch end-to-end train → checkpoint → resume → evaluate cycle

Not verified, because it needs the real dataset and a T4:

- anything about accuracy, VRAM, or runtime
- the MSD mirror's actual file layout, modality order and case count
- the pediatric cohort's label semantics, which Notebook 03 requires be checked
  independently before any WT/TC/ET conversion

## Claim discipline

`notebooks/03_locked_test.ipynb` cell 15 encodes the plan's allowed and
rejected claims. Four claims are forbidden outright unless specific evidence
exists: "state of the art", "external clinical validation", "quality-aware"
(without the A5 and A17 controls), and "interpretable gates" (without stable
gate–Shapley alignment). The pediatric cohort is an out-of-domain stress test
and must never be described as external validation.
